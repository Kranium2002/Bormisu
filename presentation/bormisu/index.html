Bormisu
Every borehole report. One verified map.
Team Tiramisu · Herrenknecht challenge · BFH 2026
Today
Ground data exists. It's just locked in reports.
Any format.
Scanned logs, handwritten field sheets, vector PDFs, Word files, spreadsheets.
Any language, any grid.
Every report brings its own language, units, depth datum and coordinate system.
Typed by hand.
Each layer copied into the Herrenknecht format, value by value. Nobody can say where a number came from.
One misread layer can mean the wrong machine underground.
