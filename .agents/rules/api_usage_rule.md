# API Key Usage Constraint

- **STRICT RULE**: The user's Mistral / OpenRouter API key (`MISTRAL_API_KEY` / `OPENROUTER_API_KEY`) is **EXCLUSIVELY** reserved for running the application's document extraction pipeline (OCR, parsing tables, and standardizing borehole logs).
- **NEVER** use this key or any user-provided API key for coding tasks, code generation, debugging, or agent development work under any circumstances.
- All code writing, software engineering, architecture, and debugging must be performed directly by the agent without consuming user API credits.
